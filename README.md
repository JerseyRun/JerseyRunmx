# Jersey Run MX - sitio gratuito

## Cómo publicarlo gratis
1. Crea una cuenta en GitHub.
2. Crea un repositorio llamado `jersey-run-mx`.
3. Sube estos archivos: `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
4. En GitHub: Settings > Pages > Deploy from branch > main > root.
5. En unos minutos tendrás una liga pública gratis.

## Antes de publicar
- Abre `script.js`.
- Cambia `PHONE = "521XXXXXXXXXX"` por tu WhatsApp real con lada.
- Ejemplo CDMX: `5215512345678`.

## Cómo actualizar inventario
En `script.js`, edita la lista `products`. Cada producto tiene jugador, equipo, número, estilo, color y tallas.

## Aviso legal
El sitio usa lenguaje de “versión fan premium” y distribuidor independiente para reducir riesgo, pero no sustituye asesoría legal.
